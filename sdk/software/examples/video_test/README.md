# Video Test

这是一个用于测试 DVI 视频动态显示的示例程序。该程序主要用于验证显存（VRAM）的动态刷新以及 CPU 向显存写入数据的性能。

## 主要功能
- 在 800x600 分辨率下，通过程序实时计算生成不断旋转变化的动态回字形（螺旋像素）彩色图案。
- 屏幕被逻辑地划分为 32x32 的网格（每个网格大小自适应屏幕比例）。
- 像素颜色信息被动态压缩转换为 8 位深度格式 (RGB332：`RRR_GGG_BB`)。
- 采用双缓冲或动态重绘的思路向显存 `0x1c400000` 连续写入帧数据以实现动画效果。

## 运行与现象
- 编译并下载运行后，外接显示器上将会显示动态变色、向内或向外扩张的彩色方块图形动画。
- 动画以特定的帧率平滑运行，证明 CPU 到显存的数据通路正常且具有足够的吞吐量。

## 编译与运行命令
在本目录下，执行以下命令进行编译：
```bash
make
```
编译完成后，生成的目标文件存放在 `obj/` 目录下（通常为可以下载的二进制文件），可通过下载工具烧录或者串口传送到板子上运行。
