# Sobel Test

这是一个用于测试 **Sobel 边缘检测硬件加速模块**与 DVI 图像显示结合的示例程序。该程序将静态图片先写入一块连续的显存中，随后利用硬件 DMA 算子读取显存进行边缘检测处理，并将处理后的边缘特征图像输出到由于 DVI 扫描显示的帧缓冲区中。

## 主要功能
- 将分辨率为 400x300 的静态图片（硬编码在 `image.h` 中的 `image_data` 数组）复制到双缓冲中的“源显存”区域内（位于目标分辨率 800x600 的中央）。
- 配置映射在 `0xbf300000` 的硬件 Sobel 算子。算子自动通过 DMA 从源显存读取像素，进行边缘提取计算后，再写入到“目标显存”。
- 轮询等待硬件计算完成后，使能 DVI 控制器将“目标显存”中的边缘检测结果输出到外接显示器。
- 图像数据采用 8 位颜色深度格式 (RGB332)。

## 运行与现象
- 编译并下载运行后，外接显示器上将会显示出一张居中的**经过 Sobel 算子处理后的边缘轮廓图**。
- 背景其他区域默认被填充为黑色。
- 整个图片处理全过程交由 FPGA 硬件计算单元完成，软件只需配置 SRC_ADDR、DST_ADDR 与 DIM 寄存器并启动即可。

## 编译与运行命令
在本目录下，执行以下命令进行编译（运行前请检查是否运行了 convert.py 脚本生成 `image.h`）：
```bash
make
```
编译完成后，生成的目标文件存放在 `obj/` 目录下（通常为可以下载的二进制文件），可通过下载工具烧录或者串口传送到板子上运行。

## 如何引入其他图片
`sobel_test` 同样使用 `convert.py` 将普通图片转换为 C 数组并写入 `image.h`，支持命令行参数。

1. 将图片放到当前 `sobel_test` 目录，或准备好其绝对/相对路径（支持 `.png/.jpg/.jpeg`）。
2. 生成 `image.h`（推荐显式指定输入）：
   ```bash
   python3 convert.py -i my_pic.jpg
   ```
3. 如需指定输出文件名或分辨率：
   ```bash
   python3 convert.py -i my_pic.jpg -o image.h --width 400 --height 300
   ```
4. 重新执行编译：
   ```bash
   make
   ```

补充说明：
- 不带 `-i` 时，脚本会自动查找输入图：优先 `test.png`、`test.jpg`、`test.jpeg`，否则选择目录下第一个支持格式的图片。
- 查看帮助：
  ```bash
  python3 convert.py -h
  ```

## 画面发糊的常见原因
除了因为使用了软硬件配合的 8 位（RGB332）通道导致的颜色损失以外：
1. **源图对比度弱**：Sobel 边缘检测依赖亮度梯度，如果图片本身的明暗对比不强烈或存在大量噪声，硬件算子算出来的边缘会显得杂乱或者过于暗淡。
2. **分辨率压缩**：目标分辨率仅为 400x300，细节边缘可能因为微小而无法在屏幕上显现。
建议使用高对比度、线条清晰的图标或者原图进行测试。
